# My Awesome App

A lightweight example app with a simple UI shell, config values, generated API stubs, and tests for PR validation.

## Features

- demo button and modal components
- central application settings
- sample generated API layer
- unit and end-to-end test examples

## Getting started

1. Open the project in VS Code.
2. Review the files in the `src` directory.
3. Extend the app with your own components and logic.

## Project layout

- `src/app.ts` - main application factory
- `src/components` - UI elements
- `src/config` - settings and secrets
- `src/generated` - generated API clients and schemas
- `tests` - automated checks
